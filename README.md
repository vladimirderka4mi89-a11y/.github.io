## 📖 О проекте

Это статья-кейс от команды **giper.ai**, в которой подробно разбирается production-пайплайн создания короткометражного рекламного ролика с использованием современных генеративных нейросетей.

Сюжет ролика: главный герой существует в мире **GTA** — похищает кофемашину, уходит от полицейской погони, терпит поражение... и просыпается на диване в реальном мире, где спокойно заваривает кофе в той самой кофемашине **KRUPS**.

Материал включает:
- Полную методологию создания карточек персонажей
- Реальные промты для `Claude`, `Nano Banana 2`, `Seedance 2.0`, `Kling 2.6`, `Suno 5`
- Разбор по актам с таймлайн-промтами для видео
- Честный разбор артефактов и ограничений нейросетей
- Финальные инсайты и выводы

## ✨ Функциональность

- **Адаптивная вёрстка** — корректно отображается на десктопе и мобильных устройствах
- **Scroll-анимации** — плавное появление блоков (`IntersectionObserver`) при прокрутке
- **Lightbox-галерея** — модальное окно для просмотра артефактов в полном размере (клик / клавиша `Esc` / клик вне окна)
- **Hover-эффекты** — зум изображений, подсветка карточек инструментов, интерактивные промт-блоки
- **Чистый Vanilla JS** — никаких зависимостей и сборщиков, всё работает "из коробки"

## 🚀 Запуск проекта

Проект не требует сборки или установки зависимостей.

```
git clone https://github.com/your-username/gta-krups-ai-video.git
cd gta-krups-ai-video
```

Просто откройте `index.html` в браузере, либо запустите локальный сервер:

```
python3 -m http.server 8000
```

или

```
npx http-server .
```

Затем перейдите на `http://localhost:8000`.

## 🎨 Дизайн-система

Все цвета и переменные вынесены в CSS custom properties:

```
--primary-blue: #1428D6;
--dark-blue: #0F2094;
--accent-lime: #D6E600;
--bg: #F5F6FA;
--surface: #FFFFFF;
--text: #1A1A2E;
--muted: #6B7089;
--border: #E2E5F0;
```

Ключевые UI-компоненты:
- `.tool` — карточки инструментов
- `.prompt-slot` — контейнеры для отображения AI-промтов
- `.act-badge` — бейджи актов сценария
- `.card-grid` / `.card-item` — сетка кликабельных артефактов
- `.pipeline` — визуализация production-цепочки
- `.lightbox-overlay` — модальное окно для просмотра изображений
