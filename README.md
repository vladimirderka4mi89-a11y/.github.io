# .github.io

## ✨ Особенности вёрстки

- **Адаптивный дизайн** — корректно отображается на мобильных устройствах (grid-раскладки автоматически перестраиваются).
- **Плавные анимации появления** (`fade-in`) блоков при скролле через `IntersectionObserver`.
- **Интерактивные hover-эффекты** для карточек, инструментов и промт-блоков.
- **Стилизованные блоки промтов** — для удобного копирования готовых промтов, использованных в проекте.
- **Пошаговые списки** (`step-list`) с нумерацией для инструкций.
- **Кастомные CSS-переменные** — легко перекрасить всю тему, поменяв значения в `:root`.

## 🚀 Как запустить

Проект не требует сборки — это статичная HTML-страница.

1. Склонируйте репозиторий.
2. Убедитесь, что папка `images/` содержит все необходимые изображения (пронумерованы согласно разметке).
3. Откройте `index.html` в браузере.

## 🧩 Ключевые инсайты, разобранные в статье

- Как создать **character reference sheet** для стабильной генерации персонажа в видео.
- Структура промта для Seedance с разбивкой по таймкодам и тегами `@` для привязки референсных изображений.
- Лайфхак экономии ресурсов — тестирование на низком разрешении перед финальным рендером.
- Почему двух вариантов генерации обычно достаточно для качественного монтажа.
- Роль человека как автора замысла и куратора результата — нейросеть выступает только инструментом.
